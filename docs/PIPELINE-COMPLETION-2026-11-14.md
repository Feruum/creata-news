# Creata News: завершение конвейера — 14 ноября 2026

## Результат

Закрыты доработки кода P1/P2 из `PIPELINE-AUDIT-2026-11-14.md`. Сохранены существующие компоненты, композиция страниц, карточки прототипа и общий стиль Creata. Источником рабочего редакционного контента теперь служит backend.

Рабочие адреса этого компьютера:

- Hermes: http://localhost:5174
- API: http://127.0.0.1:5555/health

Порт 3002 конфликтует с другим проектом, который оставлен работающим.

## Где теперь находится контент

Рабочие статьи, редакции, переводы, источники, факты, возможности, выпуски, графики, запуски, аккаунты, подписки, задания, дайджесты, доставки, события и страницы сайта хранятся в PostgreSQL.

Исходный пакет миграции находится в `backend/creata/content`. Импорт повторяемый и не перезаписывает редакционные изменения. В пакет входят три документа сайта и **246** файлов фото/видео/PDF, **86 755 657 байт**. Оригинальный PDF №01 также перенесён с прежнего внешнего хранилища. В рабочем режиме файлы выдаёт API; при настройке S3 используется S3/CDN.

Оригинальная газета сохраняет **36 полос**. Исходный HTML и все 148 уникальных ссылок на изображения/видео проверены по исходному материалу; существующие файлы сопоставлены по SHA-256. Вёрстка и взаимодействие с фотографиями сохранены, изменились адреса файлов. Исторические медиа помечены для проверки прав; неподтверждённые разрешения не выдумывались.

На фронтенде остаются компоненты, стили, интерфейсные переводы, шрифты и иконки. Старые исходные JSON и копии изображений оставлены как резервные ссылки для сверки. Приложение их больше не импортирует; старые публичные адреса `/news/photos/...` и `/newspaper/issues/...` направляются через API в управляемое хранилище.

Автоматическая проверка отклонила удаление этих старых каталогов из-за риска оставшихся ссылок. Удаление не обходилось; резервные копии сохранены. Они не являются источником рабочего контента.

## Что заполняется конфигурацией

AI-провайдер намеренно не выбран. Endpoint, модель, ключ, цены и дневной бюджет задаются в Hermes. До этого работают ручная редакция и сбор, а AI показывает «Не настроено».

Для внешнего запуска OAuth, настоящего Telegram/MTProto и S3 нужны соответствующие client ID/секреты, токен/канал/сессия и параметры bucket/CDN. Адаптеры готовы и проверены контролируемыми транспортами; реальных внешних входов, платных AI-вызовов или Telegram-рассылок в этой проверке не было.

`CREATA_WORKER_STATE_DIR` нужно сохранять между перезапусками; Compose использует `hermes-state:/app/state`. Гарантия повторного использования AI-ответа начинается после атомарной записи полученного ответа в outbox. Неизвестный исход обращения к самому провайдеру не объявляется успешным и остаётся зарезервированным.

Email/Postiz, генерация видео, генератор печатных PDF, ML-рекомендации и сообщество по исходному плану остаются следующими этапами; они не входили в исправления P1/P2 этого аудита.
