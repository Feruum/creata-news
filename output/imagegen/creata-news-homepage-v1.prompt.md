# Creata News homepage composition

Mode: built-in `image_gen` (no CLI/API fallback). Output: [creata-news-homepage-v1.png](creata-news-homepage-v1.png). The bitmap is a visual design reference; existing published content supplies the implemented website's pictures and text.

Final prompt:

Use case: ui-mockup. Asset type: high fidelity desktop homepage design reference for the existing Creata News web app, not a bitmap to replace the working website. Primary request: adapt the editorial composition of Rest of World into Creata News. Produce a crisp flat 1440px wide full browser viewport mockup, approximately 1100px tall. Color palette: warm off-white #FBFAF7, near-black #0E0E10, Creata violet #4B44F0, thin neutral rules; no gradients, no shadows, no large rounded card boxes. Typography: Archivo variable for large display headlines, Inter Regular and Medium for all reading text and interface. Brand is CR≡ATA NEWS in black with violet E mark, retained Creata visual identity. Header: compact utility links О нас / Последние новости / Дайджест, language RU / ҚАЗ / EN, theme and menu icons; a clear masthead with large centered CR≡ATA NEWS wordmark, small topic links flanking it with horizontal thin rules. Do not add many navigation rows. Main desktop layout: left column about 22% width, center about 50%, right about 24%, generous gaps. Left is a tidy bordered Latest News list headed Последние новости, short bold titles and small time/read-length metadata, small violet bullets. Center is a large editorial feature image of a technology workspace in Central Asia, with a purple small category AI И ДАННЫЕ, large bold headline below the image: «Ucode из Ташкента: ИИ собирает бэкенд за 20 минут», two lines of supporting deck and an author byline. Right column has two additional stories each with a wide photo above headline, category and author, no card containers. Below the lead grid, start editorial topic sections separated by thin rules, and a horizontal opportunities section with the existing Creata photo cards, date countdown and purple application buttons. Preserve the feel of an actual news publication with real clickable text represented in layout, not a SaaS landing page. One main headline, strong typographic hierarchy. Existing demo data will be used in implementation; photography here is conceptual only, not an assertion of an actual event. Avoid giant marketing slogans, full-bleed dark hero, floating dashboard widgets, fabricated badges, generated corporate logos, drop shadows, unrelated decorative blobs. Text in Russian as specified. This is a visual composition reference only.

Implementation uses the reference's composition with the existing Creata logo, data adapters, article images, translations, opportunity cards, Embla carousels and menus. Archivo's official Google Fonts distribution includes Latin; Inter supplies Cyrillic/Kazakh glyphs. Both fonts and their OFL licenses are self-hosted in `packages/brand/assets`.
